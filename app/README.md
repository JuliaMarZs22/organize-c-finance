# Organize-C Finance — App (front)

Painel do cliente + painel admin (React/Vite), pronto pra Vercel.

Rodar local:
```bash
npm install
cp .env.example .env   # preencha as variáveis
npm run dev
```

O passo a passo completo (Supabase, Google, deploy na Vercel) está no **`guia-de-setup.md`** na raiz do projeto.
